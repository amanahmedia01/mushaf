Dua cara: cepat lewat Safari, atau aplikasi native

Cara 1 — Pasang dari Safari (tanpa Mac)

Bisa dilakukan sekarang, tanpa akun Apple Developer.

  1. Buka https://mushaf.103-253-213-113.sslip.io/daftar-halaman.html di Safari.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambahkan ke Layar Utama, lalu Tambah.
  4. Supaya bisa dibaca tanpa internet: buka aplikasi Mushaf → Bagikan → tekan Unduh semua halaman sampai selesai.

Setelah itu ikon Mushaf muncul di layar utama, terbuka layar penuh, dan seluruh 604 halaman bisa dibaca luring.

Cara 2 — Aplikasi native (.ipa)

Perlu komputer macOS + Xcode + akun Apple Developer (US$99/tahun untuk memasang di perangkat orang lain atau App Store). Build .ipa tidak bisa dibuat dari server Linux.

Proyek Xcode-nya sudah saya siapkan (Capacitor, seluruh isi mushaf 102 MB dibundel):

Unduh proyek iOS (32 MB)

Langkah di Mac:

  1. Unduh & ekstrak ios-project-mushaf.zip.
  2. Buka Terminal: npm install lalu npx cap sync ios.
  3. cd ios/App && pod install (CocoaPods).
  4. Buka ios/App/App.xcworkspace di Xcode.
  5. Pilih target App → tab Signing & Capabilities → pilih Team (akun Apple Anda).
  6. Untuk memasang di iPhone sendiri: sambungkan iPhone, pilih perangkat, tekan Run.
  7. Untuk App Store: Product → Archive → Distribute App → App Store Connect.

Bundle ID: id.kolegaweb.mushaf · Nama tampilan: Mushaf Al-Qubba · Versi 1.0.0

Kenapa tidak ada berkas .ipa yang bisa langsung diunduh?

Apple hanya mengizinkan aplikasi iOS ditandatangani dan dikemas memakai Xcode di macOS (dan untuk dipasang di perangkat lain harus lewat App Store atau TestFlight). Server ini Linux, jadi yang bisa saya siapkan adalah proyek Xcode siap-archive seperti di atas.
